# Learning and test mixes

Mode: Operate. Inherit the existing low-light listening editor (DESIGN.md,
Inter, flat black/neutral surfaces, lime focus/data, native audio). Local
workflow extension, no new identity or composition-selection round.

Question: can I train from my included decisions and hear what the model does?
One column for training/readiness/model selection, one for an ordered test-track
list; a full-width job/result list below. On narrow screens these stack. The
primary jobs are Train from included reviews and Generate test mix. Baseline
generation is a separate explicit control. Results carry real progress, model
version, review counts and native audio/download, never decorative metric tiles.

States: pending/unchecked reviews excluded; not enough examples; queued/running;
trained but unevaluated or worse than baseline; changed reviews since training;
missing models/audio; failed/interrupted/cancelled with retry; successful render.
Draft annotations and existing completed mixes remain available during failures.
No automatic activation or musical-quality claim. Main and original navigation
must fit 1440, 768 and 390px; controls retain keyboard labels and recovery states.
