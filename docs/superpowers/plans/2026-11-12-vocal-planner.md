# Milestone 2: general vocal-preserving planner

Owner requested milestone 2 execution. Implement in this order:

1. Pure pair proposals using pinned foundation records: eight-bar default,
   sixteen bars only with complete compatible context; plain crossfade and
   protected-vocal handoff. Guard the full outgoing fade plus two preceding
   source seconds and the entire incoming overlap. Missing evidence yields
   structured review items. Return at most twelve immutable ranked candidates.
2. Select an ordered set with compatible adjacent candidates, a fixed stretch
   ratio per song and nonconflicting automation. Preserve requested/model hints
   and applied controls; unsupported model recipes fail without substitution.
3. Share sample-based envelopes, continuous stereo float preparation and mixing.
   Independently detect beats/downbeats on actual stretched sources and encoded
   audio in the isolated timeline runtime. Check whole/local overlap windows,
   original-to-output mapping, final format/levels and publication/cancellation.
4. Route explicit internal experimental Generate/Compare requests through the
   same service. Preserve legacy/default paths. UI options, durable needs_review,
   resume/correction persistence and new public request contracts remain M3.
5. Test safety/unknowns, continuous middle tracks, model constraints and both
   entry points; run real registered-pair validation, then regressions. Preserve
   old reviewed/rejected artifacts, defaults, votes and model data. No commits.

Technical validation is not listening approval. No effects, loops, source
jumps, new learned audio or automatic default promotion are included.
