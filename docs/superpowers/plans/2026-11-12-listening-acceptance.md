and one five-song order before inspecting their new results. Save catalog IDs,
original hashes, implementation hashes, and the distinction between regression,
unfamiliar pair tests, and the continuous-set integration test. These pairs are
new to the improved pipeline; they are not claimed to be source-disjoint from
all earlier reference imports or unfamiliar to the owner.

   owner feedback, with exact job/artifact identities and stated defects.

   any case used for tuning as a regression and freeze fresh independent cases.

   checks, selection hypotheses, and a request to execute M4 are not approval.
