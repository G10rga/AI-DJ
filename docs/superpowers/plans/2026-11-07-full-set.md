# Ten-track full-set render

Select ten well-supported AfroHouse entries, fit/order with the existing ML
planner, and render one continuous MP3. Prepare each excerpt once. Validate phase
at every join; downgrade unsupported long joins explicitly. Separate excerpts
locally, schedule independent incoming/outgoing vocal fades, shape instrumental
EQ per join, and add shaped tracks into a disk-backed float timeline in blocks.
Measure master headroom before encoding; decode/check the complete output and
write a tracklist/report. Keep every selected track. No commits or source edits
to the music files. Source separation and vocal-gap estimates retain their known
listening limitations.
